# PixelArt Tutor

**A local pixel art editor and visual drawing tutor for PC and iPad.**  
Пиксельный редактор для создания игровых спрайтов по точным подсказкам, от силуэта до готового персонажа.

PixelArt Tutor сравнивает рабочий спрайт с целевым PNG и показывает, какие пиксели нужно добавить, удалить или перекрасить. Он помогает рисовать самостоятельно, исправлять референсы и переносить готовые игровые ассеты в LibreSprite для анимации.

## Возможности

- **Подготовка цели:** уменьшение концепта до пиксельного разрешения, ограничение палитрой, очистка прозрачности и шума, совмещение с силуэтом.
- **Редактор:** карандаш, ластик, пипетка, рисование по подсказкам, отмена и повтор. Точные координаты, цвет и номер каждого пикселя.
- **Этапы рисования:** хранение до 20 целевых PNG в проекте, переключение, переименование, изменение порядка, импорт и экспорт. Автоматическая маска силуэта из цели; остальные этапы создаются вручную.
- **Редактирование цели:** исправляйте правый спрайт, не меняя левый. Отдельная история отмены для цели.
- **Библиотека проектов:** локальное хранение нескольких именованных проектов, миниатюры, автоматическое обновление и JSON-резервные копии.
- **Контроль качества:** цвета вне палитры, полупрозрачные пиксели, одиночные точки и маленькие островки.
- **Экспорт:** PNG, CSV, JSON и `.ase` (RGBA, один кадр, палитра, опциональные скрытые референсы и пустые слои Armor / Weapon).
- **Планшет:** режим двух холстов, синхронное перемещение, интерфейс для стилуса и касаний; режим «Перо рисует / палец двигает».
- **Офлайн:** PWA с кешем приложения после первого успешного запуска через HTTPS.

## Быстрый старт

1. Откройте `index.html` на компьютере или развернутый сайт в браузере.
2. Загрузите исходный PNG и целевой PNG. Для большого концепта используйте «Подготовить цель».
3. Загрузите палитру (PAL, GPL, PNG) или используйте встроенную Skeleton A.
4. Откройте «Проекты» и сохраните проект под именем.
5. В «Этапах» сохраните текущую цель, создайте одноцветный силуэт или импортируйте отдельные PNG. Все этапы должны иметь одинаковые размеры.
6. В режиме рисования исправляйте левый холст. Для ручного изменения референса нажмите «Редактировать цель» и рисуйте справа, затем вернитесь к рабочему спрайту.
7. Проверьте результат и скачайте `.ase` для дальнейшей анимации в LibreSprite.

Рекомендуемый порядок этапов: силуэт → анатомия → плоские цвета → свет и тень → детали. Программа не генерирует анатомию и не гарантирует художественное качество — промежуточные цели следует подготовить и проверить отдельно.

## Установка через GitHub Pages

1. Создайте публичный репозиторий (например, `pixelart-tutor`) на GitHub.
2. Распакуйте архив и загрузите **содержимое** в корень репозитория: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `README.md`. Не загружайте архив вместо файлов.
3. Откройте **Settings → Pages**. В Source выберите **Deploy from a branch**, ветку `main`, папку `/(root)`, нажмите Save.
4. После публикации откройте URL, указанный в Settings → Pages. Обычно это `https://<username>.github.io/pixelart-tutor/`.
5. Дождитесь надписи **«Офлайн: готов ✓»**. На iPad откройте сайт в Safari → Поделиться → На экран «Домой». После установки откройте приложение онлайн хотя бы один раз и дождитесь той же надписи.
6. Проверьте офлайн: включите авиарежим, полностью закройте и заново откройте приложение, откройте сохранённый проект и сделайте тестовый мазок.

Для обновления замените файлы приложения в том же репозитории. При изменениях оболочки разработчику следует повысить версию кеша в `sw.js`. При проблемах с обновлением сначала экспортируйте JSON, затем перезагрузите сайт онлайн. Не очищайте данные сайта без резервной копии.

## Управление

| Клавиша | Действие |
|---|---|
| B | Карандаш |
| E | Ластик |
| I | Пипетка |
| G | Рисовать по подсказке (левый холст) |
| Ctrl / Cmd + Z | Отменить |
| Ctrl / Cmd + Y или Cmd + Shift + Z | Повторить |
| Ctrl / Cmd + S | Скачать JSON проекта |

## Хранение и приватность

Изображения и проекты обрабатываются в браузере, без отправки на сервер. GitHub Pages предоставляет публичный код приложения, а не доступ к вашей библиотеке. Именованные проекты и последний сеанс сохраняются в IndexedDB; для совместимости сохраняется также локальная копия в localStorage, если позволяет квота. Прогресс сохраняется после мазков и периодически. Резервный JSON переносит рисунок, цель, палитру, этапы и настройки между устройствами; история отмены в JSON не сохраняется.

Браузерные данные могут быть удалены при очистке сайта, нехватке места или сбое устройства. Автосохранение не является гарантией восстановления после отключения питания. Регулярно скачивайте JSON. Автокопия на диск требует поддержки File System Access API, на Safari может быть недоступна. Синхронизации между устройствами нет.

## Ограничения и проверка

- Рабочие PNG: до 512×512; концепты для подготовки: до 4096×4096 и 16 млн пикселей. Для комфортного рисования рекомендуется 64–128 px.
- Для PWA нужен HTTPS или localhost; простое открытие локального HTML не регистрирует service worker.
- `.ase` содержит один кадр: анимации создаются в LibreSprite. Прямого импорта `.ase` нет.
- Совместимость с физическим iPad, Apple Pencil, реальный офлайн-запуск Safari и открытие экспортированных файлов в LibreSprite требуют проверки на устройстве.
- Версия 6.0 — экспериментальная сборка. Перед обновлением сохраните прежний проект в JSON; локальные файлы и опубликованный сайт используют разные хранилища.

## Структура репозитория

```text
index.html            # приложение, CSS и JavaScript
sw.js                 # офлайн-кеш приложения
manifest.webmanifest  # параметры установки PWA
icon-192.png          # иконка
icon-512.png          # иконка высокого разрешения
README.md             # документация
```

Без внешних библиотек, сервера и сборщика. Для локального тестирования PWA можно запустить `python -m http.server 8000` из папки проекта и открыть `http://localhost:8000/`.
